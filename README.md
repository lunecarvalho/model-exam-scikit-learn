## Machine Learning Model — Scikit-learn

Atividade prática desenvolvida durante a **Formação de Machine Learning em IA da Rocketseat**.

O projeto apresenta a aplicação de conceitos de **Machine Learning utilizando Python e Scikit-learn**, desde a preparação dos dados até a construção e avaliação de um modelo, com objetivo de praticar conceitos fundamentais de Machine Learning e a utilização da biblioteca **Scikit-learn** para construção e avaliação de modelos preditivos.

### Tecnologias

* Python
* Pandas
* Seaborn
* Matplotlib
* Scikit-learn
* Jupyter Notebook
